# Ticket 007 decisions

1. **Which ticket.** The frontier held 007, 009, 011, 012, 014 and 015. I took 007, the first listed. Main thread.
2. **Where the fingerprint lives.** ADR 0021 says a live encounter fingerprints its copy. Options: change `homebrew_spells` to a snapshot type holding a hash, add a parallel fingerprint list, or record it in log entry 0. Choice: a hidden `SPELL <id> (..., fingerprint <hash>)` line per entry in log entry 0, of kind `homebrew_spell`. The log is part of the state file, and the tamper hash already covers the copy. Ticket 006's `&[SpellEffect]` book API stays as it was. `SpellEffect::fingerprint()` is public so batch reports can reuse it. The line is hidden because it would show players a monster's spells. Main thread.
3. **Where the start checks live.** A new `stat_block::check_live_casts(block, book)` runs ticket 006's slot-level check and then the homebrew rules: section against `casting_time`, never `traits` or `legendary_actions`, no `long`, and a `spellcasting` block for a leveled attack or save spell. Messages name the stat block, the action, its section and the casting time. Only homebrew entries are checked, so SRD fixtures are untouched. Main thread.
4. **What counts as a save or attack spell.** `Effect::rolls_against_target` is true for Attack, SavingThrow, MoveThenAttack and CounterSpell, and looks inside an Area and a timed modifier's `on_end`. A damage-only spell such as Magic Missile is a utility spell and needs no block. Main thread. The auditor asked whether any other variant forces a roll. None does.
5. **The warning.** `start` returns `warnings` on `Outcome`, left out of the JSON when empty, with one line per ability and missing id. It fires for any id the book lacks, including an unmodeled SRD spell, since both resolve as `unmodeled_cast`. Main thread.
6. **`bench add`.** The ticket was silent. Choice: a stat block added mid-fight goes through `check_live_casts` against the encounter's spells, so a misplaced homebrew cast can't get in after start. Main thread. The auditor raised a replay risk for old saves. There is none: every stat block already runs the SRD slot check when parsed, and old saves have no homebrew entries.
7. **`--spell` on a running encounter.** Options: let clap reject the unknown flag, or accept a hidden `--spell` on the shared `--encounter` args and refuse it in `open()`. Choice: the hidden arg, so the message points to `bench start`. Every command on a running encounter goes through `open()`. The command catalog now skips hidden args. Main thread.
8. **Monster `--slot`.** Refused in the engine's `with_slot` when the stat block has no `class`. Batch never passes a slot, so batch is unaffected. Main thread.
9. **Upcast gate.** ADR 0005 says the engine ignores a cast's `upcast`, and ADR 0022 says a higher `--slot` takes effect only when it is true. Choice: the gate applies to homebrew entries only, so SRD `--slot` behavior is unchanged. With `upcast: false`, a `--slot` above the entry's level is refused, naming both fixes, instead of spending the slot for nothing. A stat block's own `slot_level` is not gated, since the user reviews it before start. Main thread. The auditor asked about refusal against a silent no-op, and about the stat block path. It accepted both choices in round 2.
10. **Spell-cast window.** No code change was needed: the engine already opens the window for any leveled cast outside a reaction. A new engine test shows a homebrew leveled cast opens one and a homebrew cantrip or reaction cast does not. Main thread.
11. **Version and docs.** Engine 0.1.38, a changelog entry, and the curve's `engine_version` edited by hand. Batch numbers are unchanged, as the calibration test confirms. The live-mode skill now says the engine refuses `--slot` for monsters. The homebrew skill text is left for ticket 010. Main thread.
12. **Tests.** Added one test per start refusal (section mismatch for all three casting times, traits, legendary actions, long, attack spell with no block, save spell with no block, SRD id clash), monster `--slot`, PC upcast with and without `upcast: true`, the warning, a PC and a monster homebrew cast with replay from a saved copy, `bench add`, the homebrew window test, and a CLI test. The CLI test deletes the spell file before casting and replaying, and checks the `--spell` refusal on `state`, `end-turn` and `replay`. 517 core and 28 CLI tests pass, 578 in all. Clippy shows only the two warnings master already has.
13. **Audit.** One haiku auditor. Round 1 raised seven items: two choices to confirm (items 6 and 9 above), the replay risk (item 6), `Outcome` serde, `--spell` coverage, a missing save-spell test and possible effect variants. I added the save-spell test and a `replay --spell` check and answered the rest. Round 2: APPROVE.
14. **Skipped gates.** No requirements or implementation confirmation was asked, per the runner's override. No remote CI runs on a branch push (the only workflow is the tag-triggered release), so step 6 was skipped. The thread was renamed to the ticket name.
