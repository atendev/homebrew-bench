# Ticket 015 decisions

Rounds per round for spell durations, a grilling ticket resolved in auto mode. A sonnet grilling subagent answered the questions and a haiku auditor checked the result. The audit verdict is APPROVE, after three rounds.

1. **Which ticket.** The frontier held "Rounds per round for spell durations" and the Disintegrate ticket. I took the first one. Main thread.
2. **Premise.** The ticket says Shield and Haste last one turn. The options were to accept the premise or correct it. The choice was to correct it. Haste uses concentration and its lethargy uses `until_end_of_next_turn`, so `rounds` does not touch it. The affected effects are Shield, Sleep's Incapacitated and homebrew `rounds`. The main thread recommended it and the grilling subagent accepted. Auditor: pass.
3. **What `rounds: N` means.** The options were (a) the round clock, as long durations use, (b) source-anchored, ending at the start of the source's Nth turn after it lands, or (c) per-turn counting kept, plus a new `until_start_of_next_turn` unit. The choice was (b), because it matches Shield's text and the rules' reading of "1 round". The main thread recommended it and the grilling subagent accepted. Auditor: pass.
4. **Gate.** The options were (a) a new recorded `settings.round_durations`, (b) folding it into `long_durations`, or (c) no gate. The choice was (a), because (b) would change how saves already recorded with `long_durations` refold. The main thread recommended it and the grilling subagent accepted. Auditor: pass after the Sleep exception was added (item 7).
5. **How the count runs.** The options were (a) to tick `Rounds(n)` when the source's initiative slot comes up, with no new field, or (b) to store the source's turn count. The choice was (a). The grilling subagent added two checks: an effect applied during its source's own turn first ticks at the source's next turn, and the tick runs before the forfeit skip. The main thread recommended it and the grilling subagent accepted. Auditor: pass.
6. **Missing or downed source.** The options were (a) to count a downed source's slot and use the round clock only when the source is None or out of the initiative order, or (b) to use the round clock whenever the source is down. The choice was (a), which keeps one rule. The grilling subagent raised the case and the main thread refined it. Auditor: pass.
7. **Sleep data.** In round 2 the choice was to change Sleep's Incapacitated to `until_end_of_next_turn` with no gate. The auditor found that a refold reads SRD entries from the embedded data, so an old Sleep save's expiry event moves. That reopened the question. The options were (a) keep `rounds: 1`, (b) edit with no gate and accept the event-log drift, or (c) edit and add a Sleep-specific engine branch. The grilling subagent chose (b), following the See Invisibility precedent from ticket 113. The build ticket now states the drift and adds a test that hit points and end states match as recorded. Auditor: pass after the Old saves bullet named the exception.
8. **Batch numbers.** The choice was that the build regenerates the curve and the spell panel and re-picks panel fixtures if control win rates moved. Policy stays v5, since it already reads `rounds` as rounds. The main thread recommended it and the grilling subagent accepted. Auditor: pass.
9. **Shield's later-turn AC.** The options were to score it in the policy now or leave the policy alone. The choice was no policy change, and the ticket records it as a known conservative bias. The main thread recommended it and the grilling subagent accepted. Auditor: accepted, since the method text in code backs it.
10. **Docs.** The choice was a "Round duration" glossary term, a paragraph in ADR 0005 and no new ADR, as ticket 109 did. The CONTEXT.md term waits for the build, so the glossary does not describe behavior the engine lacks. The main thread made that call, the grilling subagent accepted, and the auditor passed it.
11. **Intake mapping.** "1 round" and "until the start of your next turn" map to `rounds: 1`, and "until the end of its next turn" maps to `until_end_of_next_turn`. "Until the end of your next turn" on another creature is written `rounds: 1` and flagged as inferred. The main thread recommended it and the grilling subagent accepted. Auditor: pass.
12. **Surfaced items.** The engine never runs `delayed` effects (Acid Arrow, Vitriolic Sphere). That and caster-anchored end-of-turn durations went to Not yet specified, not to tickets. The main thread recommended it and the grilling subagent accepted. Auditor: pass.
13. **Build ticket.** I created one `task` ticket, "Build rounds per round" (020), and made it block Spell baseline. The map's blocker list keeps closed blockers, as 017 does, so it reads [015, 019, 020]. The auditor caught a first draft that dropped 015, and the main thread fixed it.
14. **Auditor objections not acted on.** The HITL ticket closed without the user. Auto mode has the grilling subagent answer in place of the user, and the user signs off at the commit gate. The auditor accepted this.
15. **Skipped gates.** The user was not interviewed, per auto mode. The thread rename succeeded.
